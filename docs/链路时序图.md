## 链路骨架

```
【输入】
 麦克风阵列(4麦)  →  音频通路(采样率/重采样/增益)
   │
【前端处理】
  ├─ 3A: AEC / ANS / AGC
  ├─ 波束成形 / DOA
   │
【唤醒与端点】
  ├─ 唤醒: WakeUp.bin (本地)
  ├─ VAD + 端点判定 (VAD_DNN?  VAD_ENDPOINT_TIMEOUT = ____ ms)
   │
【识别】
  ├─ 流式 ASR: 百度 bdasr_aipd  (分包 ____ ms/包,  PID ____)
   │
【理解与对话】
  ├─ 语义理解 + DM (百度 nlu/dm)
  ├─ 车控执行 / 技能分发 / 多轮状态
   │
【输出】
  ├─ TTS: 百度 tts (在线 / 离线音库)
  ├─ 播放器 + 音频焦点 + ducking
   │
  └↺ 回声参考信号回灌 AEC  (参考信号取自: ____________________)
```
