## 3 · 对比表 ★

| 指标 | 原始带噪 | 降噪后 | 理想参考 | 判读 |
|---|---|---|---|---|
| 分段 SNR (dB) | | | — | 提升幅度是否够 |
| PESQ (MOS) | | | 4.4+ | 听感质量 |
| STOI | | | 0.95+ | 可懂度，**严重降噪时比 PESQ 更敏感** |
| **VOS / 语音失真** | | | 越接近越好 | **过度降噪会在这里暴露** |
| LUFS | | | — | 响度是否被改变 |
| **处理延迟 (ms)** | — | | — | **必须记**，进端到端预算 |
| 常驻内存 (MB) | | | — | 车机上是事故级约束 |

### 判读要点

- **PESQ 涨了但 STOI 没涨** → 降噪"听起来干净了"，但可懂度没改善，可能是过度降噪损伤了辅音。
- **VOS 明显偏离** → 语音被处理损了，这个信号 PESQ 和 STOI 都盖不住。
- **SNR 提升很大但延迟不可接受** → 工程上不可用，不管指标多好。

## 4 · 结论（3–5 句，必须给出场景边界）

> 示例结构：
> "在这类 **XX** 噪声下，XX 方案把分段 SNR 从 X dB 提升到 Y dB，但 PESQ 只从 A 升到 B，
> 说明**过度降噪损伤了语音**；代价是 Z ms 延迟与 W MB 内存。
> **结论：XX 场景可用（余量充足），XX 场景不可用（会吃掉端到端预算的 Z%）。**"
