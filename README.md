# VoiceStack-Bench

> **同一块车机开发板上，三套语音栈的对照评测台。**
> A 百度语音 SDK（级联）· B 百度端到端 SDK · C 自研开源栈
> 目标不是造一个更好的语音助手，而是给出一张**能支撑技术选型决策**的对比数据表。

---

## 为什么做这个

车载语音的选型目前是个黑箱：Tier1 集成商业 SDK，算法团队给指标，测试报 bad case，
但**没人系统地回答过"这三个方案在真实车况下差多少、代价是什么、什么时候该用哪个"**。

这个仓库要回答的就是这个问题。评测跑在同一块板子上、同一套噪声数据集、同一套指标口径，
结论以**数字**呈现，而不是感受。

**三栈的分工**

| | A · 百度语音 SDK | B · 百度端到端 SDK | C · 自研开源栈 |
|---|---|---|---|
| 形态 | 级联（ASR→NLU→TTS） | Speech-to-Speech 一体化 | 级联，但全栈自选可离线 |
| 状态 | 量产在用，最熟 | 商用新架构，待实测 | 本项目搭建 |
| 独有视角 | **知道它什么时候会挂** | 迁移成本评估 | 对照基线 |

三者互为参照：A 是生产现实，B 是演进方向，C 是可控性基准。
