# 噪声数据集

> 车载语音的成败，八成取决于这套数据集覆盖得真不真实。
> **来源优先级：真实车内实录 > 回放模拟 > 纯软件加噪。**
> 只有纯软件加噪的结果，不能作为量产结论。

## manifest.csv 字段

| 列 | 说明 |
|---|---|
| `sample_id` | 唯一编号，与 `results/` 里的 `sample_id` 对应 |
| `instruction` | 标准答案文本（评测 CER 的基准） |
| `category` | 车控 / 导航 / 媒体 / 电话 / 闲聊 |
| `noise_type` | wind / road / music / multi_speaker / nav / quiet |
| `snr_db` | **实测** SNR，非估算 |
| `speed_kmh` | 车速（wind / road 适用） |
| `window_open` | 开窗状态 |
| `seat` | 录音座位（主驾 / 副驾 / 后排） |
| `speaker` | 说话人（多说话人场景必填） |
| `raw_path` | 原始音频相对路径（文件本身不入库） |
| `collected_at` | 采集日期 |
| `device` | 采集设备 |
| `note` | 备注 |

## SNR 档位规划

| 档 | 目标 SNR | 主要来源 | 备注 |
|---|---|---|---|
| S0 | ≥35 dB | 怠速 / 录音棚 | 基线 |
| S1 | 20–30 dB | 城市道路 60–80km/h | 日常频发 |
| S2 | 10–20 dB | 高速 100–120km/h、开窗 | 难点 |
| S3 | ≤10 dB | 强风、雨天、音乐全开 | 极端 |

---

## 采集建议

- **指令集 ≥100 条**，取自真实车控高频指令，覆盖不同音长（1 字 / 3 字 / 长句）。
- 同一条指令在每档噪声下 **≥3 次**，避免单样本偶然性。
- 建议补两类"机器话"样本：导航播报、其他座位乘客说话 —— 这两类是**误唤醒与误打断的主因**。
- 记录 **座舱状态**（车速、开窗、音乐音量、空调风量），这些都会影响实际表现。
- 原始录音体积大，不入库；但**必须保留可追溯的对应关系**。
