## 笔记规范

每篇笔记一个文件，命名 `<主题>-W<周次>.md`，开头固定三行：

```markdown
**一句话结论**：____________
**能回答什么问题**：____________
**来源**：文档 / 论文 / 源码 / 实测
```

> **"能回答什么问题"这一栏最重要。** 写不出来，说明这篇笔记还不值得写。
> 面试时能拿出来讲的，就是这栏非空的那些。
